Goal

      
Write function think(s). It runs once per tick for your bot and must return an action. Reduce the enemy's HP to 0, or have more HP after 200 ticks.

      
Actions

      
    
        
  • "forward" move 1 cell in the direction you face (blocked by walls and the enemy)
    • 
        
  • "left" / "right" rotate 90°
    • 
        
  • "shoot" fire along your facing line (costs 3 energy, hits the first bot, 20 damage)
    • 
        
  • "shield" costs 1 energy; a shot hitting you this tick does only 5 damage
    • 
        
  • "wait" do nothing (energy still recharges: +1 per tick, max 10)
    • 
      

      
What you can read from s

      
    
        
  • s.me, s.enemy → {x, y, dir, hp, energy}   (dir: 0=N 1=E 2=S 3=W)
    • 
        
  • s.enemyInSight — you face the enemy with a clear line
    • 
        
  • s.enemyAimingAtMe — the enemy faces you with a clear line
    • 
        
  • s.wallAhead, s.isWall(x, y), s.cols, s.rows, s.tick
    • 
        
  • s.orbs → [{x, y, d}] repair orbs (+30 HP); s.nearestOrb (or null); d = steps to walk
    • 
        
  • s.dist(a, b) Manhattan distance between two {x,y}
    • 
        
  • s.random() seeded random number in [0,1)
    • 
        
  • s.memory an object that survives between ticks
    • 
      

      
Ready-made helpers (BFS path-finding!)

      
    
        
  • s.stepToward(x, y) → action that follows the shortest path to a cell
    • 
        
  • s.stepAway(x, y) → action that moves farther from a cell
    • 
        
  • s.aimAt(x, y) → "left"/"right" to face a target that is in a straight clear line, "shoot" if already facing it, else null
    • 
      

      
Rules of the arena

      
    
        
  • Both bots decide at the same time. Order: turn → shield → move → shoot → pick up orbs → recharge.
    • 
        
  • Because movement happens before shots, a bot that dodges out of a line can make an aimed shot miss.
    • 
        
  • The map is rotationally symmetric, so neither side has an advantage. Orbs appear in mirrored pairs.
    • 
        
  • Your code runs in a sandbox. If it loops forever, the fight is cancelled after a few seconds.
    •
